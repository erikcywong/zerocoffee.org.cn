# Credits and licences

## Introduction film

**Music.** Original score composed for this film inside this repository
(`home-video/music_v4.py`): C major, 104 BPM, marimba ostinato over piano chords,
pad and a soft low pulse, synthesised sample-free with additive synthesis.

It is original work, so there is **no licence to buy, no attribution to give and
no Content ID registration** to fight. That matters here: the earlier candidate was
a Pixabay cue (free, but Content ID registered), and the "green / eco" CC0
collections on archive.org turned out to be re-uploads of other people's music
with a CC0 tag attached — legally void, because you cannot dedicate rights you
do not hold.

**Level.** The bed is set from the track's own integrated loudness to a target of
**-34 LUFS**, then sidechain-compressed 8:1 under the narration. Measured on the
published cuts, the music sits about 18 dB below the voice and the whole mix reads
only +0.3-0.4 dB above the narration alone.

**Narration.** Synthesised with Microsoft Edge neural voices (`en-US-AndrewNeural`
for English, `zh-CN-XiaoxiaoNeural` for Mandarin) via `edge-tts`. Generated audio
for a website voiceover; not a clone of any real person.

**Earlier cues.** `piano_calm.wav`, `piano_assurance.wav` and `lavender_hill.wav`
were also generated here and remain in the repository unused.
`goldberg_aria.mp3` is J.S. Bach's Goldberg Variations Aria performed by Kimiko
Ishizaka (CC0 1.0, Open Goldberg Variations); it was used in an earlier published
cut and is kept only for reference.

**Fonts.** System fonts only (`Segoe UI`, `Microsoft YaHei`). No webfont is
downloaded, so there is no font licence to carry.

**Icons.** Drawn as inline SVG in this repository.
