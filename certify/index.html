2 · Run the case

480 → 500 labels a year at 240,000 plantlets.

What the case does
  1. Locks scope: boundary, functional unit, batch definition.
  2. Reviews the method and factor provenance.
  3. Verifies metering, sampling and the ledger.
  4. Independent technical review signs off.
  5. Issues a label id + hash and writes it to the register.
A case can be refused: if the metered share is too low for the requested grade, a real file would come back qualified rather than labelled. This simulator always issues — read the grade, not the stamp.
