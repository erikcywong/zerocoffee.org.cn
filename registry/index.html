Every label carries its own hash and commits to the label before it. The chain can be recomputed here, in your browser, without calling any server — that is the whole point of publishing it.

How the chain is recomputed

Each record commits to the previous label's hash and to four of its own fields. Change any digit in batch, total, per_unit or grade and the recomputed hash stops matching — and because every later label commits to this one, the entire tail breaks with it.

hash = fnv( prev_hash + "batch|total|per_unit|grade" )
