Digital platform

A label you can check without trusting us

The registry, the hash and the recomputation routine are public. Our server is a convenience, not a dependency — if it disappears, a printed label still verifies.

Registry

Public label registry

Every issued label gets an ID, a hash, an issue date and a revocation slot. Revoked labels stay listed with the date and reason.

How a label is frozen

01Compute the payloadbatch | total_kgCO2e | per_unit | grade
02Chain ithash = fnv(prev_hash + payload) — the previous label's hash is committed, so the set is append-only
03PublishRegistry entry, public page, QR on the physical label
04Re-derive on demandAnyone can recompute; a mismatch is visible to them, not to us first
